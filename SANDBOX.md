# Hugh's Golf Sandbox

This copy is for enhancement work and testing only.

- App folder: `sandbox/HughsGolf_Web_sandbox`
- DB file: `sandbox/HughsGolf_Web_sandbox/HughsGolf.db`
- Default port: `8446`
- Live/QNAP port remains `8445`

Run locally with:

```bash
python3 app.py
```

Then open:

```text
http://localhost:8446
```

Do not deploy this folder directly to QNAP. Move finished fixes/enhancements back through the main repo lane first.
